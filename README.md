# SecureDev Rails Architecture Demo

A Ruby on Rails application demonstrating secure architectural patterns and OWASP Top 10 mitigation strategies.

## Tech Stack
- Ruby on Rails 7
- PostgreSQL
- Devise (Authentication)

## Features (In Progress)
- Vulnerable-by-design endpoints for educational purposes.
- Patched services demonstrating remediation.
- Custom authorization layers.
